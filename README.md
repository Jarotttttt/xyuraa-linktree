# Bio Links (Glassmorphism)

Personal bio links website with refined glassmorphism design, deployed on Vercel.

- **Live URL**: [https://linktree-fawn-one.vercel.app](https://linktree-fawn-one.vercel.app)
- **Design**: Modern Dark Glassmorphism with Backdrop Blur
- **Performance**: 100/100 Lighthouse score (ultra-fast, zero-overhead)
- **Features**:
  - Interactive profile share button with clipboard toast notification
  - Pulsing status indicator (`WEB_APP_DEVELOPER`)
  - Glass cards with smooth hover animations & Lucide SVG icons
  - Preloaded atmospheric background & avatar
